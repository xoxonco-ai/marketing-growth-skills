### 關於 Rube MCP

標註「透過 Rube MCP」的技能是操作說明，本身不會連線。要實際使用，必須先把 `https://rube.app/mcp`（Composio 提供的第三方服務）加入 MCP 伺服器設定，並為每個服務（Slack、Notion、Stripe 等）完成 OAuth 授權。授權後 Composio 會取得該帳號在授權範圍內的存取權，請只授權需要的服務與權限。
